# odoo17-custom
# Odoo 17 ERP System

This project is a structured Odoo 17 ERP platform.

## Structure
- addons/ → Odoo core & third-party modules
- custom_addons/ → Custom development modules
- docker/ → Development & production environment
- config/ → Odoo configuration
- scripts/ → automation scripts
- docs/ → documentation

## Run Development
cd docker/dev
docker compose up -d
